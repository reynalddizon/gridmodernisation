# Building a grid for the age of power: scrollytelling (GridMod4)

GridMod4 is the final version. It follows the analysts' updated script and is built on GridMod3, which is kept unchanged for version control. The interventions part (Within reach onwards) is carried over from GridMod3 while it is still being worked out.

This version gives the illustrations a hand-drawn finish, with organic edges, fine ink contours and print grain, while keeping them flat. The original version is still in the GridMod folder.

This is the first working draft of the Grid Modernization visual explainer.

## Open it
Double-click `index.html`, or run `python3 -m http.server` in this folder and go to http://localhost:8000.
You need to be online the first time so the Poppins font can load. Everything else is included in this folder.

## Notes and open questions
1. **Categories.** These follow the Highway Code sign sheet. In the concept note's time/cost grid, some items are coloured differently: demand response, battery storage and flexible plants show as Reinforce there, and digital twins and cybersecurity show as Optimize. One version needs to be confirmed.
2. **Sources.** Every "The technology" panel says "Source link to be added". Solid vs. dashed follows the concept note.
3. **Colour and skin tone:** every figure uses the lightest brown (Brown 1). In the illustrations, browns and oranges/reds are shifted one tone lighter, still using palette values, for a softer pastel feel. The figures have no faces, on purpose. Every filled shape has a fine ink outline.
4. **Illustrations** are flat vector drawings in Ember colours, not AI images. The poster art you sent was used as the mood reference for the three eras.
5. **Icons** come from Ember's licensed Font Awesome Pro Sharp set, which is internal use only. Check the licence before publishing this outside Ember.

### Modernising the grid (index4, concept 3)
Sections C and D follow "Grid mod_Project concept 3": the Act 4 intro, the 17 numbered interventions and the time and cost matrix. The charts and tab shields are gone.
- `js/data4.js`: the categories (Optimise 1-9, Reinforce 10-14, Expand 15-17), each item's script header and description (verbatim), its technologies (name, icon, a point on the city `at:[x,y,z]` and a preferred label offset `off:[dx,dy]`), the camera `view:[x,y,zoom]`, the sets kept in colour (`focus`), and the matrix cells and note.
- `js/story4.js`: a second copy of the one city (`#scene-city4`) in its finished state. A sticky text box per category: the category name, an icon bar of its items (icons, not shields; click to jump), and the current item's number, header and description. On each item the camera moves to it, everything else washes out, and each technology appears as a callout on the city: a dot, a short leader and a small square card (square corners, black border) with the technology's shield above its name, centred.
